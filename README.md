# Community Resilience Hub

Simple multi-page website prototype for the TU Dublin Global Citizenship group project.

**Beyond Poverty** — Why food and clean water matter, and a technical solution that links all three.

- SDG 1 No Poverty
- SDG 2 Zero Hunger
- SDG 6 Clean Water

## Pages

- `index.html` — Project title, problem statement, proposal overview
- `solution.html` — The three modules of the hub
- `sdgs.html` — How the project maps to the SDGs
- `users.html` — Target users, persona and simple user journey
- `demo.html` — Basic interactive demo (status check + form) using plain JavaScript

## How to view

Open any HTML file in a browser, or enable GitHub Pages on this repository (Settings → Pages → Deploy from main branch).
